## Overview

This repository contains the complete analytics engine, methodology whitepaper, interactive web dashboard, and Rajasthan Royals IPL 2027 auction recruitment model for **SupeRR Selector Season 2**.

Using proprietary ball-by-ball delivery records (200,999 balls across 867 IPL and T20I matches from 2022 to 2026), this project establishes a mathematically validated **Pressure Performance Index (PPI)** to distinguish players who rise to the occasion from those whose performance dips under stress.

### Mandatory BCCI / IPL Eligibility Compliance
In strict compliance with BCCI regulatory policy, all Pakistani players have been excluded from the rankings to ensure that every recommendation is 100% actionable for the Rajasthan Royals War Room at the IPL 2027 auction.
